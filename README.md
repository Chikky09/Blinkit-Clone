# Blinkit Clone

A frontend clone inspired by Blinkit, designed to replicate the user interface of an online grocery delivery platform.

## Features

* Responsive design
* Product cards
* Navigation menu
* Category sections
* Modern e-commerce UI

## Technologies Used

* HTML5
* CSS3
* JavaScript
